# VibeDL

YouTube から最高の「Vibe（雰囲気）」をそのままに、音量を完璧に整えて保存するインテリジェント音声ダウンローダー。  
ダウンロードから音量ノーマライズ、メタデータ埋め込みまでを一括で行う Windows 専用ツールです。

## 主な機能

- 🔄 **高品質ダウンロードと変換**  
  最適な音声ストリームを自動選択し、MP3 / M4A に変換（ビットレート選択可：192k、256k、320k など）

- 🔊 **ラウドネスノーマライズ（LUFS）**  
  Spotify や YouTube Music と同じ -14 LUFS に自動調整。曲ごとの音量差を解消

- 🛡️ **音割れ防止（True Peak Limiter）**  
  ピークレベルを -2.0 dB に制限し、歪みを徹底排除

- 🏷️ **メタデータ自動埋め込み**  
  タイトル、アーティスト名、アルバムアート（サムネイル）を自動で書き込み（MP3 / M4A 両対応）

- 🎵 **プレイリスト一括ダウンロード**  
  プレイリスト URL を入力するだけで全曲をまとめて取得可能

- 🧹 **ファイル名自動クリーン**  
  `[公式]` や `MV` などの不要タグを除去し、OS 互換の安全なファイル名に

- ⚙️ **設定のカスタマイズ**  
  保存先、フォーマット、ビットレート、ノーマライズ／メタデータの ON/OFF を自由に変更可能  
  （設定は Windows レジストリに保存され、次回起動時に自動復元）

- 🚀 **ポータブル & 単体完結**  
  FFmpeg を内蔵（PyInstaller でバンドル時）しており、インストール不要でどこでも動作

## 動作環境

- Windows 10 / 11
- インターネット接続が必要
- （ソースコードから利用する場合）Python 3.9+ と FFmpeg

## インストール

### 実行ファイル版（推奨）
1. [Releases](https://github.com/fancyverbena/VibeDL/releases) から `VibeDL.exe` をダウンロード
2. 任意のフォルダに置いてダブルクリックするだけ

### ソースコードから

```bash
git clone https://github.com/fancyverbena/VibeDL.git
cd VibeDL
pip install -r requirements.txt
python src/main.py
```

#### 必要な外部ソフトウェア（ソースコード版のみ）

FFmpeg がシステムの PATH に通っている必要があります。実行ファイル版には内蔵されているため不要です。

## 使い方

### 起動時のメニュー

起動すると次のようなメニューが表示されます：

```
========== VibeDL v1.1 ==========
 保存先: C:\Users\...\downloads
 フォーマット: mp3 / 256k
 音量正規化: ON (-14.0 LUFS)
 メタデータ: ON
---------------------------------
 1: YouTubeからダウンロード
 2: プレイリストをダウンロード
 3: 設定を変更する
 0: 終了
---------------------------------
選択してください >
```

### 基本的な操作

#### ① 単一/複数の動画をダウンロード

1. メニューで `1` を選択
2. URL を入力（スペース区切りで複数指定可）
3. 処理が自動進行し、指定フォルダに出力されます

#### ② プレイリストを一括ダウンロード

1. メニューで `2` を選択
2. プレイリストの URL を入力
3. プレイリスト内の全曲を順にダウンロードします

#### ③ 設定変更

メニューで `3` を選ぶと、以下の項目を変更できます：

| 設定項目 | 説明 |
|--------|------|
| **保存フォルダ** | 絶対パスで出力先を指定（例：`C:\Users\YourName\Music`） |
| **出力フォーマット** | `mp3` または `m4a` |
| **ビットレート** | 例：`192k`、`256k`、`320k` |
| **目標音量 (LUFS)** | デフォルトは `-14.0`（多くのストリーミングサービスと同等） |
| **音量正規化** | `ON`（推奨）/ `OFF` |
| **メタデータ埋め込み** | `ON`（推奨）/ `OFF` |

> 💡 変更は即座にレジストリへ保存され、次回起動時も引き継がれます

## 音量ノーマライズについて

YouTube 上の動画はそれぞれ音量が異なります。VibeDL は **EBU R128 準拠のラウドネスノーマライズ** を行い、すべての曲を一定の体感音量に揃えます。

- **目標値** `-14 LUFS` は Spotify、YouTube Music、Apple Music などの基準と同じです
- **True Peak Limiter** により、ノーマライズ後でも音割れ（クリッピング）が発生しないよう設計されています
