# VibeDL - 究極のオーディオダウンローダー

YouTubeから最高の「Vibe（雰囲気）」をそのままに、音量を完璧に整えて保存するためのインテリジェント・ダウンローダーです。  
ダウンロード時の音量差の自動解消や、高音質なMP3変換を、シンプルなコマンドライン画面から操作できる単体完結型ツールです。

## 主な機能
- 🔄 **最高品質の自動抽出と変換**: YouTubeから最適な音源を取得し、256kbpsの高品質MP3へ変換
- 🔊 **音量の自動チェックと更新**: ストリーミング標準（-14 LUFS）への自動ノーマライズ
- 🛡️ **音割れガード（True Peak Limiting）**: 強力なリミッターを搭載。ピークを -2.0dB で固定し、音割れを徹底排除
- 🧹 **ファイル名の自動クリーンアップ**: タイトルに含まれる特殊文字を除去し、OSに最適な命名を実施
- 🚀 **ポータブル設計**: FFmpegを本体に内蔵しているため、インストール不要でどこでも動作
- 📊 **高音質維持**: 独自のエンコード設定により、変換による劣化を最小限に抑制
- ⚡ **シームレスな処理**: ダウンロードから音量正規化までをワンクリック感覚で実行
- 📂 **自動保存機能**: 実行ファイルと同じフォルダに整理された状態でファイルを出力

## インストール

### リリースからインストール
1. [Releases](https://github.com/あなたのユーザー名/VibeDL/releases) から最新の実行ファイルをダウンロード
2. ダウンロードした `VibeDL.exe` を実行

## 使い方
起動後、以下のようなメニュー画面が表示されます：
========== VibeDL - Audio Downloader ==========
Loudness Target : -14.0 LUFS
True Peak Limit : -2.0 dB
Output Format   : MP3 (256kbps)
YouTubeのURLを入力してください:

### 主な操作の流れ
1. **VibeDL.exe** を起動
2. ダウンロードしたいYouTube動画のURLを貼り付け、`Enter` キーを押す
3. 自動的に「1. ダウンロード」「2. 音量正規化」が進行
4. 完了メッセージが表示されると、フォルダ内にMP3が生成されています

### 音量正規化（LUFS調整）について
- 複数の動画を落としても、すべての曲が人間が心地よいと感じる一定の音量に揃います
- 寝る前の視聴やプレイリスト再生時に、曲によって音量を変える手間がありません
- `-14 LUFS` は YouTube Music や Spotify 等の主要配信サービスと共通の音響基準です
