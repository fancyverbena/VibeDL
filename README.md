# VibeDL

YouTube から最高の「Vibe（雰囲気）」をそのままに、音量を完璧に整えて保存するインテリジェント音声ダウンローダー。
ダウンロードから音量ノーマライズ、メタデータ埋め込みまでを一括で行う **Windows 専用 GUI ツール**です。

## 主な機能

### 📥 ダウンロード

* **YouTube から高品質音声を取得**：最適な音声ストリームを自動選択し MP3 / M4A / WAV / FLAC に変換
* **ビットレート選択**：128k / 160k / 192k / 256k / 320k
* ⏱️ **時間指定ダウンロード**：`1:30-2:45` のように範囲を指定して部分的に保存
* 🔍 **キーワード検索**：アプリ内で YouTube を検索し、結果から直接ダウンロード
* 📄 **テキストファイルインポート**：URL リストをまとめて読み込み
* ⬆️ **キュー & 並列処理**：複数 URL をキューに追加し、最大2並列で効率的にダウンロード
* 🔗 **URL 履歴**：過去10件のURLをドロップダウンから再選択可能
* 📋 **クリップボード監視**：YouTube URLをコピーするだけで自動入力（設定でON/OFF）
* ▶️ **ダウンロード後すぐ再生**：完了したファイルをその場で再生

### 🔊 音声処理

* **ラウドネスノーマライズ (-14 LUFS)**：Spotify や YouTube Music と同じ基準に自動調整
* **True Peak Limiter (-2.0 dB)**：音割れを徹底防止
* **無音トリミング / フェードイン・アウト**（近日追加予定）

### 🏷️ メタデータ

* **自動埋め込み**：曲名、アーティスト名、アルバムアート（サムネイル）を MP3 / M4A / FLAC に書き込み
* **ファイル名テンプレート**：`{title} - {uploader}` のように自由に命名規則を設定

### 🎨 UI/UX

* 🖥️ **直感的な GUI（wxPython）**：タブ分け設定画面、進捗バー、速度表示
* 🌙 **ダークモード**：目に優しい配色に切り替え
* 🔔 **通知機能**：完了時にサウンド + Windows トースト通知
* 🌐 **多言語対応**：日本語 / English（設定で切替）

### ⚙️ その他

* **ポータブル設計**：PyInstaller で単一 exe 化可能（FFmpeg 自動ダウンロード）
* **FFmpeg 自動セットアップ**：未導入時は初回起動時に自動取得

## インストール

### 実行ファイル版（推奨）

1. Releases から最新の `VibeDL.exe` をダウンロード
2. 任意のフォルダに配置し、ダブルクリックで起動
3. 初回起動時に FFmpeg の自動ダウンロードが提案されます

### ソースコードから

```bash
git clone [https://github.com/fancyverbena/VibeDL.git](https://github.com/fancyverbena/VibeDL.git)
cd VibeDL
pip install -r requirements.txt
python src/main.py
```

補足：ソースコードから実行する場合、FFmpeg がシステム PATH に通っている必要があります。実行ファイル版では自動ダウンロードされます。

### 基本的な操作
1. URL を入力（履歴から選択、またはクリップボードから自動入力）
2. 必要に応じて開始・終了時間を指定（例：1:30 ～ 2:45）
3. 「キューに追加」をクリック
4. 複数 URL を追加したら「キューを開始」
5. 処理が進行し、完了すると通知でお知らせ
6. 「▶ 再生」ボタンで保存したファイルをすぐに聴けます

### 検索機能
* 🔍 ボタン（または URL 欄右の虫眼鏡）をクリック
* キーワードを入力すると YouTube の検索結果が表示され、選択してキューに追加

### インポート機能
* 📄 ボタンでテキストファイル（1行1URL）を読み込み、まとめてキューに追加

## 音量ノーマライズについて
* YouTube 上の動画は音量がバラバラです。VibeDL は **EBU R128** 準拠で全曲を同じ体感音量に揃えます。
* 目標値 **-14 LUFS** は Spotify / YouTube Music / Apple Music と同一基準。
* **True Peak Limiter** により、ノーマライズ後もクリッピング歪みは発生しません。
