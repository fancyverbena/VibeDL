# VibeDL

YouTube から最高の「Vibe（雰囲気）」をそのままに、音量を完璧に整えて保存するインテリジェント音声ダウンローダー。
ダウンロードから音量ノーマライズ、メタデータ埋め込みまでを一括で行う **Windows 専用 GUI ツール**です。

## 主な機能

### 📥 ダウンロード

* **YouTube から高品質音声を取得**：最適な音声ストリームを自動選択し MP3 / M4A / WAV / FLAC に変換
* **ビットレート選択**：128k / 160k / 192k / 256k / 320k
* ⏱️ **時間指定ダウンロード**：`1:30-2:45` のように範囲を指定して部分的に保存
* 🔍 **キーワード検索**：アプリ内で YouTube を検索し、結果（最大10件）から複数選択してキューに追加
* 📚 **プレイリスト対応**：プレイリストURLを入れると中身を展開してまとめてキューに追加
* 📄 **テキストファイルインポート**：「インポート」ボタンやドラッグ＆ドロップで URL リストをまとめて読み込み
* ⬆️ **キュー & 並列処理**：複数 URL をキューに追加し、最大2並列で効率的にダウンロード。キューにはサムネイル・タイトル・長さを表示
* ▶️ **ダウンロード後すぐ再生**：「▶ 再生」ボタンや履歴から完了ファイルをその場で再生
* 🕘 **ダウンロード履歴**：完了したファイルの一覧から再生・再ダウンロード
* 🔗 **URL 履歴**：過去のURLをドロップダウンから再選択可能
* 📋 **クリップボード監視**：YouTube URLをコピーするだけで自動入力（設定でON/OFF）

### 🔊 音声処理

* **ラウドネスノーマライズ (-14 LUFS)**：Spotify や YouTube Music と同じ基準に自動調整
* **True Peak Limiter (-2.0 dB)**：音割れを徹底防止
* ✂️ **無音トリミング / フェードイン・アウト**：先頭・末尾の無音を自動カットし、フェード（0.5〜10秒）も適用可能（設定でON/OFF）

### 🏷️ メタデータ

* **自動埋め込み**：曲名、アーティスト名、アルバムアート（サムネイル）を MP3 / M4A / FLAC に書き込み
* **ファイル名テンプレート**：`{title} - {uploader}` のように自由に命名規則を設定

### 🎨 UI/UX

* 🖥️ **直感的な GUI（PySide6 / Qt）**：タブ分け設定画面、進捗バー、速度表示、ダークモード
* 🌙 **ダークモード**：目に優しい配色に切り替え
* 🔔 **通知機能**：完了時にサウンド + トレイ通知
* 🌐 **多言語対応**：日本語 / English（設定で切替、再起動後に反映）

### ⚙️ その他

* **ポータブル設計**：PyInstaller で単一 exe 化可能（FFmpeg 自動ダウンロード）
* **FFmpeg 自動セットアップ**：未導入時は初回起動時に自動取得
* **プレイリスト対応（CLI版）**：`--playlist` でプレイリストを一括ダウンロード
* **テキストファイル読み込み（CLI版）**：`--file` で URL リスト（1行1URL）を一括処理
* **ブラウザCookie対応**：設定で Chrome / Edge / Firefox のCookieを使うよう指定でき、年齢制限などの動画に対応

## インストール

### exe版（おすすめ）

[Releases](https://github.com/fancyverbena/VibeDL/releases) から最新の `VibeDL.exe` をダウンロードして実行してください。

> **初回起動時の注意**: 起動時に「Windows によって PC が保護されました」と表示される場合があります。これはコード署名がまだないための Windows SmartScreen の確認画面で、マルウェアの警告ではありません。「詳細情報」→「実行」の順に押すと起動できます。（署名の取得を進めています）

### ソースコードから

```bash
git clone [https://github.com/fancyverbena/VibeDL.git](https://github.com/fancyverbena/VibeDL.git)
cd VibeDL
pip install -r requirements.txt
python src/gui.py
```

補足：GUI版の入り口は `src/gui.py` です。コマンドライン版を使う場合は `python src/main.py` で起動します（設定はGUI版と共通で、レジストリに保存されます）。FFmpeg が見つからない場合は、初回起動時に自動ダウンロードが提案されます（ダウンロードされた FFmpeg は変換・ノーマライズの両方に使われます）。

### 基本的な操作
1. URL を入力（履歴から選択、またはクリップボードから自動入力）
2. 必要に応じて開始・終了時間を指定（例：1:30 ～ 2:45）
3. 「キューに追加」をクリック
4. 複数 URL を追加したら「キューを開始」
5. 処理が進行し、完了すると通知でお知らせ
6. 保存先の「開く」から保存フォルダをそのまま開けます

### 検索機能
* URL 欄の右にある「検索」ボタンをクリック
* キーワードを入力して検索すると、結果が「タイトル ― 投稿者（長さ）」で最大10件表示される
* 複数選択して「選択をキューに追加」、またはダブルクリックで1件を即追加
* メイン画面で開始・終了時間を指定していれば、検索から追加した分にも適用される
* 検索結果には利用できない動画（地域制限・削除・非公開など）が混ざる場合があり、その場合はリトライせずエラーとして表示される

### インポート機能
* 「インポート」ボタンでテキストファイル（1行1URL）を読み込み、まとめてキューに追加
* テキストファイルや URL をウィンドウへドラッグ＆ドロップしても追加できます
* CLI版では `python src/main.py --file urls.txt` でも処理できます

## 音量ノーマライズについて
* YouTube 上の動画は音量がバラバラです。VibeDL は **EBU R128** 準拠で全曲を同じ体感音量に揃えます。
* 目標値 **-14 LUFS** は Spotify / YouTube Music / Apple Music と同一基準。
* **True Peak Limiter** により、ノーマライズ後もクリッピング歪みは発生しません。

## Pro ライセンスについて

基本機能は無料で使えます。Pro ライセンスキーを設定画面（全般タブ）に入力すると、以下が解放されます。

* 同時ダウンロード数 3〜10（無料版は2まで）
* チャプターごとに分割して保存
* 保存先テンプレートでのフォルダ分け（`{uploader}/{title}` のように `/` が使えます。`{date}` は投稿日）
* 字幕がある動画では歌詞として埋め込み
* 正規化のトゥルーピーク上限の指定

キーはオフラインで署名検証されるため、利用時にインターネット接続は不要です。

## exeのビルドと配布

単一ファイルの exe（`VibeDL.exe`）を PyInstaller で生成できます。

### ビルド

```
build.bat
```

依存パッケージのインストール、アイコン生成（`tools/make_icon.py` → `assets/icon.ico`）、PyInstaller の実行まで自動で行い、`dist\VibeDL.exe` が生成されます。設定は `VibeDL.spec`、ビルド専用の依存は `requirements-build.txt` にあります。

### 配布（GitHub Releases）

1. `build.bat` で exe を生成
2. リポジトリの Releases から「Draft a new release」を開く
3. タグ（例：`v1.0.0`）を作成し、`dist\VibeDL.exe` を添付して公開

### exe版の注意

* FFmpeg は同梱していません。PATH に無い環境では、初回起動時に自動ダウンロードされます（SHA256 検証付き）。
* 未署名の exe のため、初回実行時に Windows SmartScreen の警告が出る場合があります。
